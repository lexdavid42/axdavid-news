**TL;DR:** Google launched the Elephant-Goldfish plugin that forces coding agents to create specs first and run five zero-context review stages before any code is written.

**Why it matters:** This changes how AI writes software by making the agent prove the plan before producing code. Fewer surprises and less rework for freelancers and small teams who ship features fast. It also gives a repeatable audit trail you can show clients.

**What to do:**
- Test the plugin on a small feature to compare bug counts and review time.
- Start using one-page spec templates so agents have clearer acceptance criteria.
- Optional: include agent review logs in client deliverables to win trust.
