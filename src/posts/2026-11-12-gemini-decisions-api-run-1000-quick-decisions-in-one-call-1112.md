**TL;DR:** Google launched the Gemini Decisions API, which evaluates up to 1,000 yes/no, choice, or rubric questions against one multimodal input in a single pass with 150–250 ms latency and no output‑token charges.

**Why it matters:** This makes automating routine choices — approvals, lead scoring, content checks, and simple rubrics — far faster and cheaper. You can evaluate many discrete rules against an image, file, or text at once. That cuts latency and cost for apps that need mass decisioning.

**What to do:**
- If you run or build apps that make repetitive yes/no or scoring calls, prototype a batch decision endpoint using the Gemini Decisions API.
- Swap sequential checks for single-pass scoring to cut response time and token costs.
- Optional: benchmark latency and accuracy against your current service before full migration.
